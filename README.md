# Практическая работа №3

## Конфигурация и безопасность веб-службы

## 📌 Описание

В рамках работы реализована ASP.NET Core веб-служба с централизованной конфигурацией и механизмами базовой защиты приложения.

Проект поддерживает:

* загрузку настроек из нескольких источников
* проверку конфигурации при запуске
* ограничение доверенных источников (CORS)
* ограничение частоты запросов (Rate Limiting)
* security headers
* режимы Training и Production

---

## 🧱 Реализованные механизмы

### Конфигурация

Настройки приложения загружаются из:

* `appsettings.json`
* environment variables
* command line arguments

Поддерживается приоритет конфигурации.

---

### Проверка настроек

Перед запуском выполняется валидация:

* корректность лимитов
* корректность origin
* допустимые режимы приложения

При неверной конфигурации приложение не запускается.

### Безопасность

Реализованы:

* CORS policy
* Rate Limiting
* Security Headers
* обработка ошибок

---

### Режимы работы

Поддерживаются два режима:

* `Training`
* `Production`

В зависимости от режима изменяется поведение приложения и обработка ошибок.

---

## 📁 Основные файлы проекта

* `Program.cs` — настройка приложения и middleware
* `AppOptions.cs` — модель конфигурации
* `AppOptionsValidator.cs` — проверка настроек
* `SecurityHeadersMiddleware.cs` — security headers
* `ErrorHandlingMiddleware.cs` — обработка ошибок
* `InMemoryItemRepository.cs` — хранилище данных

---

## 🧪 Проверки

### ✅ Проверка конфигурации

Проверено чтение настроек из:

* JSON
* environment variables
* command line arguments

---

### ✅ Проверка CORS

* trusted origin → запрос разрешён
* untrusted origin → запрос блокируется

---

### ✅ Проверка Rate Limiting

После превышения лимита сервер возвращает:

```text
429 Too Many Requests
```

### ✅ Проверка режимов

Training:

* подробные ошибки
* режим разработки

Production:

* более безопасный режим
* сокращённая информация об ошибках

---

### ✅ Проверка Security Headers

Проверено наличие:

* `X-Frame-Options` - запрещает вставлять твой сайт во фрейм на другом сайте (защита от кликджекинга).
* `Cache-Control` - директива кеширования.

## 📌 Использованные паттерны

## 📌 Вывод

В результате работы реализована защищённая ASP.NET Core веб-служба с централизованной конфигурацией, проверкой настроек и механизмами безопасности.

Приложение поддерживает различные режимы работы и может изменять поведение без изменения исходного кода.
